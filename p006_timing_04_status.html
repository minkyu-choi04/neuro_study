0. 결과를 읽기 위한 배경: P001, P006, A/A2/A3의 역할

P001은 공통 영화의 Camera/Scene Cut을 각 subject의 neural onset으로 매핑하고, 그 onset을 기준으로 신경 반응의 baseline/post window를 구성하는 우리 데이터 준비 단계입니다. P006은 이 준비된 timestamp가 원 저자가 사용한 annotations_patient_aligned와 어떤 관계에 있는지 검토하기 위해 시작한 독립적인 timing audit입니다. 원본 연구의 patient-aligned annotation은 우리가 다운로드한 같은 NWB 안에 포함되어 있습니다.

Phase A는 원본 환자별 cut onset과 P001 onset을 같은 사건으로 매칭하려 했습니다. A2는 왜 매칭에 실패했는지 후보를 단계별로 조사하고 watchlog의 두 clock step 차이를 분석했습니다. A3 v003은 frame-convention과 window anomaly를 분류했으며, v004는 검증 가능한 source snapshot·provenance·manifest 절차를 강화한 반복 진단입니다. 즉 v004는 새로운 timing correction 실험이 아니라 A3 결과를 더 엄격하게 출처와 묶어 남긴 것입니다.

1. P006은 어디서 멈췄나?

Event identity matching funnel

오해 방지: “31,578개가 matched”가 아닙니다. 31,578개는 watchlog 안에서 가까운 clock row를 찾은 것입니다. 그 row가 P001의 동일한 physical cut이라는 objective proof는 없습니다.

1A. 위 funnel을 실제로 해석하기

원본 NWB의 annotations_patient_aligned에서 Camera Cut과 Scene Cut의 value=1인 구간 시작 32,234개를 모았습니다. 이 개수는 29 subject를 합친 patient-aligned label row 개수이지 서로 다른 영화 컷의 총 개수가 아닙니다. 한 사람이 같은 컷을 여러 번 보고, skip하거나 aligned interval 구조가 달라질 수도 있어서 공통 annotation 수와 단순히 29를 곱한 수가 일치할 필요는 없습니다.

그중 31,578개는 해당 환자의 neural onset 근처 20ms 안에서 유일한 cleaned-watchlog locator를 찾았습니다. 하지만 그 watchlog row가 원본과 동일한 canonical Camera/Scene Cut을 가리킨다는 영화 frame·재생 segment identity 증명은 통과하지 못했습니다. 나머지 656개는 그 20ms 범위에 locator가 없었습니다. 따라서 accepted identities는 0입니다.

A2에서 나타난 대략 −40ms의 후보 movie-PTS 차이는 매우 흥미로운 한 프레임 신호지만, 실제로 동일한 cut에서의 neural onset 오차가 −40ms라는 결론은 아닙니다. 그 차이를 timing correction으로 승인하려면 원 저자의 upstream alignment 규칙과 독립적인 event correspondence 증거가 필요합니다.

2. 무엇이 evidence이고 무엇은 결론이 아닌가?

v004 findings / claims separation

v004의 validation.json은 verified_dual_clock_available: false이며, 결과 status는 UNRESOLVED_ALIGNMENT_IDENTITY입니다. 이는 timestamp가 “0 ms 차이”라는 뜻도, “틀렸다”는 뜻도 아닙니다.

3A. 서로 다른 분모를 왜 구분해야 하나?

1,091은 원본 영화 전체에서 선택한 Camera/Scene Cut 관련 주석 행의 수입니다. Camera Cut과 Scene Cut이 같은 physical transition에서 동시에 발생할 수 있기 때문에, physical transitions는 970개입니다. 이 수들은 영화에 독립적으로 몇 개의 event label이 있는가를 표현합니다.

28,110은 v004의 window_evidence가 다루는 mapped physical transition × subject × playback occurrence 수입니다. 반면 1,005,458은 분석에 필요한 neuron identity가 추가된 q0 manifest의 identity row 수입니다. 한 event가 여러 neuron에 대응하므로 더 큰 값입니다. 594,146은 이전 P003의 M0와 M1을 동일 관측치에서 비교한 held-out neuron-event pairs로, 특정 fold와 model-validity 선택이 적용된 또 다른 모집단입니다.

이 분모가 다른 상태에서 “clock anomaly 1건이 100만 observation 중 1건이므로 무시해도 된다”라고 계산하면 안 됩니다. 먼저 anomaly가 특정 subject와 event window를 침범하는지 보고, 그 후 해당 event가 몇 개의 neuron row와 어떤 primary fold에 대응하는지 순서대로 집계해야 합니다.

마찬가지로 421,650은 28,110개의 mapped occurrences 각각에 대해 3개 window와 5개 임시 threshold를 조합한 transition-summary 집계 수입니다. 그만큼 서로 다른 event를 추가 수집했다는 뜻이 아닙니다.

4. 아직 완료되지 않은 이유 — 두 개의 빈 칸

필요한 evidence가 missing인 정확한 위치

첫 번째 bridge는 original `aligned_labels.npy` 생성 경로나 독립적으로 확인 가능한 source-frame identity가 필요합니다. 두 번째 bridge는 처리된 watchlog만 보는 것에서 벗어나 raw frame presentation과 TTL/acquisition 변환의 근거가 필요합니다. 이 자료가 공개되지 않았다면 불확실성을 명시한 채 연구 설계를 제약해야 합니다.

코드 해석의 추가 제한: A3의 source-convention 함수는 optional `objective_identity_evidence`를 지원하지만 실제 v004 run에서는 넘겨주지 않았습니다. “source-supported proposals = 0”은 objective correspondence 부재의 독립적인 경험적 증명이 아닙니다.

4A. 그림의 두 Missing Bridge가 뜻하는 과학적 한계

Bridge A — 같은 컷인지 먼저 증명

원본 annotations_patient_aligned는 이미 각 환자의 neural 시간에 맞춰진 결과표입니다. 원 저자의 writer는 중간파일 aligned_labels.npy를 읽지만 그 파일을 만드는 원래 upstream 과정 전체가 공개된 것은 아닙니다. 따라서 환자의 원본 row 하나가 movie의 어느 canonical frame과 어떤 replay occurrence에 대응하는지 명확히 역추적할 수 있어야 합니다. 이 대응을 증명하지 않은 채 P001과 원본 onset을 빼면 잘못된 서로 다른 사건의 timestamp를 비교할 위험이 있습니다.

v004의 source-convention helper는 optional objective_identity_evidence를 받는 구조이지만 production은 이 증거 없이 수행되었습니다. 따라서 source-supported proposal 0은 원본에서 절대 그런 mapping이 존재하지 않는다는 뜻이 아닙니다. 현재 공개 자료로 검증 가능한 proof를 넣지 못했다는 점이 중요합니다.

Bridge B — watchlog의 정확성 독립 검증

cleaned_watchlogs 한 행에는 영화 PTS와 neural-recording timestamp가 짝지어져 있습니다. P006 A3는 이 값의 인접 step 차이, pause, seek, 큰 gap을 분류할 수 있습니다. 하지만 두 값 모두 이미 처리된 로그 안에 있으므로, 원래 실험 laptop의 실제 frame presentation 기록 및 acquisition system의 TTL 원시 evidence와 다시 비교한 독립적인 시계 변환 검증과는 다릅니다.

따라서 verified_dual_clock_available=false는 오류가 입증됐다는 뜻이 아니라, 가용 자료만으로 전체 dual-clock correctness를 인증할 수 없었다는 뜻입니다.

5. 앞으로 어떤 순서로 마무리할까?

1
이미 수집한 QC 결과를 이해 가능한 exposure 수치로 요약

v004 evidence에서 subject × event × primary folds(1/2/3) 기준, pause/seek/gap와 baseline/post/raster의 교집합을 재집계. 모델 fitting 불필요.

2
Source-level event identity를 독립 검증할 수 있는 자료 탐색

원본 aligned-label 생성 규칙, frame indexing, annotation identity, replay provenance. 단순 nearest ±40ms 확대는 금지.

3
동일 event가 검증되는 경우에만 paired Δt 계산

subject, type, segment, drift, tails를 포함한 signed onset residual을 보고. 불가능하면 unresolved를 기록하고 overclaim하지 않음.

4
과학적 rule 또는 다음 phase는 별도 승인

event retiming, clock tolerance, neural timing sensitivity, Figure 7, M0/M1 refit은 P006 A3 승인에 포함되지 않음.

5A. 그래서 다음 실험에서 바꿔야 하는 것은 무엇인가?

지금 당장 timestamp를 40ms 이동시키거나 event를 제외하는 것은 잘못된 순서입니다. 첫째, original aligned-label 생성 경로를 추가로 확인할 자료가 있는지 조사하고 독립적 movie frame/subject occurrence identity를 얻어야 합니다. 둘째, 이미 생성된 v004 q0_identity_exposure.parquet와 window_evidence.parquet를 읽어 실제 primary fold의 baseline/post/raster가 clock anomaly와 얼마나 중첩되는지 구체적인 표로 제시해야 합니다. 셋째, event identity가 입증될 경우에만 paired neural onset residual을 계산합니다.

이것들이 해결되기 전까지의 정확한 결론은 UNRESOLVED_ALIGNMENT_IDENTITY이며, 기존 P001/P003의 frozen 결과가 자동 무효화되거나 검증 완료로 격상되는 것은 아닙니다. 새로운 timing acceptance rule이나 neural model rerun은 별도의 연구 의사결정이 필요합니다.
