Study Material 03 · Project-wide design

왜 M0 → M1 → M2 → M3 → M4로
feature scope를 조금씩 넓히는가?

이 장은 Topic 1 전체 experiment의 논리를 설명합니다. 특히 DINOv2와 VGGish가 어떤 sensory quantities를 만드는지, cut을 기준으로 visual/audio가 시간상 어떻게 선택되는지를 현재 frozen configuration 그대로 보여줍니다.

1. 한꺼번에 모든 feature를 넣지 않는 이유

Scene Cut에서 neuron firing이 커졌다고 해도 그 이유가 정말 “scene structure”인지, 아니면 단순히 화면과 소리가 크게 바뀌었기 때문인지 구분해야 합니다. 그래서 이전 model을 고정한 채 새 predictor block 하나만 추가합니다.

M0 — nuisance
baseline activity + slow movie-time drift
M1 — sensory
M0 + immediate visual/audio discontinuity
M2 — structural
M1 + current scene/location/character/speech structure
M3 — preceding context
M2 + past history before the transition
M4 — interaction
matched transition/control dataset에서 Event × Context
핵심 논리: 각 단계가 “이전 단계로 이미 설명한 것 이상으로 새 정보가 held-out neural response를 설명하는가?”를 묻습니다.

3. M1의 역할: “그냥 화면/소리가 크게 바뀐 것 아닌가?”

M1은 structural/context interpretation 전에 immediate sensory discontinuity를 먼저 설명합니다. 현재 frozen plan에서는 DINOv2 pre/post cosine distance가 primary high-level visual change scalar이고, VGGish pre/post cosine distance는 optional/descriptive auditory scalar입니다.

DINOv2

각 video frame을 high-level visual embedding으로 바꾸는 vision foundation model입니다. 이 프로젝트에서는 neuron model 자체가 아니라 visual change measurement tool로 사용합니다.

VGGish

VGG-style CNN을 audio log-mel representation에 적용한 general audio embedding model입니다. speech-only가 아닙니다. speech, music, environmental sound 등 다양한 audio content를 representation합니다.

4. 중요한 수정: DINO는 “한 pre-frame vs 한 post-frame”이 아니다

현재 Topic 1 frozen sensory definition은 25 fps canonical movie에서 다음 visual windows를 사용합니다.

pre visual window = [−1.00 s, −0.04 s)
post visual window = [+0.04 s, +1.00 s)

즉 cut 바로 직전/직후의 단일 frame만 비교하지 않습니다. 각 window 안의 여러 frame의 DINO embeddings를 평균합니다.

25 fps이므로 frame 간격은 0.04초입니다. cut과 맞닿은 frame을 바로 쓰지 않고 ±0.04초 gap을 둡니다. 개념적으로는:

각 pre frame → DINO embedding z_t → 평균 → z_pre
각 post frame → DINO embedding z_t → 평균 → z_post

visual discontinuity = 1 − cosine(z_pre, z_post)
왜 평균하나? 한 frame의 우연한 motion/blur/compression artifact보다, transition 전후 약 1초의 대표 visual state 차이를 더 안정적으로 측정하려는 목적입니다.

5. Cut과 visual frame의 정확한 temporal relationship

canonical frame rate가 25 fps이므로 한 frame은 40 ms입니다. event time을 t=0이라 하면 current frozen visual selection은 대략 다음 의미입니다.

... −1.00                     −0.04 | 0 | +0.04                      +1.00 ...
      [      PRE frames           )   CUT   [          POST frames       )

cut 직전 40 ms frame과 cut 직후 첫 경계 frame을 직접 섞지 않고
전후 window를 분리해 평균 representation을 만든다.

실제 implementation은 canonical_time_sec에 대해 half-open window를 적용합니다. 따라서 pre는 t ≥ event−1.0이고 t < event−0.04, post는 t ≥ event+0.04이고 t < event+1.0입니다.

6. VGGish: “1초 window”라는 말은 두 층으로 나눠 이해해야 한다

현재 정확한 값: VGGish embedding 하나의 effective waveform receptive field는 0.975초입니다. 그리고 event-level pre/post summary를 만들 때는 1초 길이의 anchor-selection windows를 씁니다.

6.1 VGGish embedding 하나

Native VGGish anchor가 시간 t에 있다면, 그 embedding은 미래를 보지 않고 t에서 끝나는 과거 0.975초 audio를 요약합니다.

VGGish embedding at anchor t ≈ audio from (t−0.975 s) to t

실제 extraction은 canonical [t−1.04,t)를 assembly한 뒤 최종 0.975초 receptive field를 사용합니다. Native anchors는 0.2초 간격입니다.

6.2 Event-level pre/post anchor selection

pre anchor window = (−1.0 s, 0.0 s]
post anchor window = (0.0 s, +1.0 s]

각 구간에 들어오는 native VGGish anchor embeddings를 모아 평균한 뒤 pre/post cosine distance를 계산합니다.

그래서 post VGGish가 완전히 “post-only audio”는 아닙니다. 예를 들어 t=+0.2 s인 post anchor는 과거 0.975초를 보므로 대략 −0.775 s부터 +0.2 s까지를 포함합니다. 즉 상당한 pre-cut audio가 섞입니다. 이것이 현재 VGGish를 primary sensory scalar로 쓰지 않고 optional/descriptive로 두는 중요한 이유입니다.

Optional/descriptive auditory change scalar

8. 왜 cosine distance인가?

d = 1 − (z_pre · z_post) / (||z_pre|| ||z_post||)

Embedding의 방향이 비슷하면 cosine similarity가 높고 distance는 작습니다. representation이 크게 바뀌면 distance가 커집니다. 이 값은 neuron response를 직접 예측하는 deep network output이 아니라, transition마다 붙는 scalar sensory predictor입니다.

9. M2: sensory를 설명한 뒤에도 structure가 남는가?

M2는 M1을 그대로 유지하면서 current structural variables를 추가합니다.

Scene Cut

annotation-defined structural transition.

Location change

전후 장소가 바뀌는가.

Character configuration

등장인물 구성이 바뀌는가.

Speech continuity/change

speech state의 continuity 또는 변화.

M2−M1 improvement가 있다면 “current structure가 immediate sensory discontinuity를 넘어서 추가 정보를 준다”는 좁은 주장을 할 수 있습니다. 아직 long-context hypothesis는 아닙니다.

10. M3: 현재가 아니라 “어떻게 여기까지 왔는가?”

M3에서는 event 이전 history만 사용합니다. 예: current scene duration, time since previous major transition, recent cut density, location persistence, character persistence. Primary context timescale 후보는 30초이며 10/60초는 robustness candidates입니다.

past 30 s -------------------------------→ EVENT
[scene persistence][recent cuts][location history] | t=0

질문:
같은 current sensory/structural transition이라도
preceding history가 다르면 rapid post-event firing이 달라지는가?

11. M4: context가 단지 baseline state를 바꾼 것인지 구분

M3에서 context가 predictive하더라도 context가 전체 firing state를 바꾼 것일 수 있습니다. 그래서 non-transition control times를 만들어 transition vs control을 비교하고 Event × Context interaction을 봅니다.

log E[y] = nuisance + sensory/structure + β_E Event + β_C Context + β_EC(Event×Context)

βEC 또는 interaction model의 held-out improvement가 핵심입니다. 이것이 “context가 transition response 자체를 modulation한다”는 가장 강한 confirmatory direction입니다.

12. 이 전체 design의 한 문장 요약

먼저 nuisance를 설명하고 → immediate sensory를 설명하고 → current structure를 설명하고 → 그 모든 것을 넘어 preceding context가 predictive한지 보고 → 마지막으로 그 context effect가 transition-specific response modulation인지 matched controls로 검사한다.
