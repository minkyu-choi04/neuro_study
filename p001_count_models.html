P001 · Count modeling chapter

Baseline을 왜 빼지 않고 covariate로 넣는가?
그리고 왜 Poisson / Negative Binomial인가?

P001에서 만든 baseline spike count와 post-transition spike count가 이후 모델에 어떻게 들어가는지 이해하기 위한 장입니다. 수식보다 먼저 직관을 잡고, 그 다음 P001/P002의 Negative Binomial 모델과 연결합니다.

1. 먼저 하나의 P001 row를 다시 보자

Subject S07 · Unit 018 · Occurrence E0523

baseline window [-1.0, -0.2) : 3 spikes   (0.8 s)
transition                    : t = 0
post window     [ 0.0,  1.0) : 6 spikes   (1.0 s)

이 row에서 모델이 궁극적으로 설명하려는 값:
Y = post spike count = 6

여기서 baseline count는 “이 neuron이 transition 직전 어떤 firing state에 있었는가”에 대한 정보를 줍니다. 같은 neuron이라도 occurrence마다 baseline state가 달라질 수 있습니다.

핵심: 우리가 알고 싶은 것은 단순히 “post가 baseline보다 몇 개 늘었나?”만이 아닙니다. baseline state와 다른 nuisance factors를 감안했을 때, 이 transition의 sensory/structural/context features가 post count를 얼마나 설명하는가?가 모델의 질문입니다.

2. 가장 직관적인 방법: post − baseline

처음 보면 아래 계산이 가장 자연스럽습니다.

response = post count − baseline count

예를 들어 baseline=3, post=6이면 response=+3입니다. 하지만 P001의 primary windows에서는 중요한 문제가 바로 생깁니다.

Baseline

[-1.0, −0.2)

길이 = 0.8 s

Post

[0.0, 1.0)

길이 = 1.0 s

즉 raw count 3과 6은 서로 같은 시간 길이에서 센 숫자가 아닙니다. 단순히 6−3=3이라고 하면 baseline 쪽이 20% 더 짧다는 사실을 무시합니다.

그럼 firing rate로 바꿔서 빼면 되지 않나?

baseline rate = B / 0.8     post rate = Y / 1.0
rate difference = Y/1.0 − B/0.8

이렇게 하면 window duration 문제는 해결됩니다. 하지만 여전히 statistical modeling 관점에서는 몇 가지 정보와 유연성을 잃습니다.

3. Subtraction의 핵심 한계

① 두 noisy measurements를 합쳐버림

Post도 random count이고 baseline도 random count입니다. 둘을 빼면 두 measurement의 noise가 모두 하나의 숫자에 들어갑니다.

② count outcome을 잃음

post−baseline은 −3, 0, +5처럼 음수가 될 수 있습니다. 더 이상 Poisson/NB의 자연스러운 nonnegative count outcome이 아닙니다.

③ baseline 효과를 고정해버림

단순 subtraction은 baseline을 어떤 정해진 비율로 빼겠다고 미리 결정합니다. 실제 post와 baseline의 관계가 그 비율인지 데이터가 판단할 수 없습니다.

세 번째 문제가 특히 중요하다

같은 neuron에서 baseline firing이 높은 occurrence일수록 post firing도 자연스럽게 높은 경향이 있을 수 있습니다. 그런데 그 관계가 정확히 “baseline 1 spike 증가 → post에서도 정확히 1 spike 증가”일 이유는 없습니다.

OccurrenceBaseline countPost count단순 post−baseline
A15+4
B47+3
C810+2

이 표만 보고도 baseline이 높은 상태에서는 post도 높은 경향이 보입니다. 그런데 우리가 알고 싶은 것은 그 baseline dependence를 고려한 뒤에도 event feature가 post를 설명하는가입니다.

4. Baseline as covariate: 무엇을 하는가?

Subtraction 대신 post spike count를 그대로 outcome Y로 유지하고 baseline count B를 predictor 중 하나로 넣습니다.

Yi = post spike count for occurrence i
log( μi ) = β0 + βBBi + β1X1i + β2X2i + ···

여기서 μi는 그 occurrence에서 모델이 예상하는 post spike count입니다. B_i는 baseline count이고, X들은 movie time, sensory feature, structural/context feature 등 단계별 predictors가 될 수 있습니다.

중요한 차이: subtraction에서는 baseline을 얼마나 빼는지가 미리 정해져 있습니다. covariate 방식에서는 βB를 데이터에서 추정합니다. 즉 “baseline state가 post firing과 얼마나 강하게 연결되는가?”를 model이 학습합니다.

log link가 있다는 것은 무슨 뜻인가?

Poisson/NB GLM에서는 평균 count가 음수가 될 수 없도록 보통 log link를 씁니다.

μi = exp( β0 + βBBi + ··· )

따라서 βB는 raw spike를 단순히 몇 개 더하는 효과라기보다 expected count를 multiplicative하게 조정합니다. 예를 들어 βB=0.10이면 baseline count가 1 증가할 때, 다른 조건이 같다면 expected post count는 약 exp(0.10)=1.105, 즉 약 10.5% 커지는 식입니다.

5. 왜 spike count에 Poisson distribution이 자연스러운 출발점인가?

Spike는 0,1,2,3,…처럼 세는 discrete event입니다. 일정한 시간 window 안에서 발생한 event 수를 모델링하는 가장 기본적인 분포가 Poisson입니다.

P(Y=y | λ) = e−λ λy / y!
E[Y] = λ      Var(Y) = λ

λ는 한 window에서 예상되는 평균 spike count입니다.

Poisson의 직관

아주 단순화해서, 작은 시간 구간마다 spike가 낮은 확률로 발생하고 서로 거의 독립적이며 firing rate가 그 window 안에서 비교적 일정하다면, 일정 window의 총 spike count는 Poisson으로 근사될 수 있습니다.

GLM에서는 λ를 features에 연결한다

Yi ~ Poisson( μi )
log( μi ) = Xiβ

즉 sensory change가 크거나 Scene Cut이거나 preceding context가 특정 상태일 때 expected spike count μ가 어떻게 달라지는지 regression으로 추정할 수 있습니다.

6. 그런데 Poisson에는 강한 제약이 있다: mean = variance

Poisson은 평균이 5이면 variance도 반드시 5라고 가정합니다.

Poisson:   Var(Y) = E[Y] = μ

하지만 실제 neural firing은 occurrence마다 숨은 상태가 다릅니다.

attention+arousal+network state+unmodeled stimulus+slow drift

그래서 똑같아 보이는 조건에서도 어떤 occurrence는 0 spikes, 어떤 것은 2, 어떤 것은 12처럼 예상보다 훨씬 넓게 퍼질 수 있습니다. 이를 overdispersion이라고 합니다.

overdispersion:   Var(Y) > E[Y]
주의: 모든 neural spike count가 항상 overdispersed인 것은 아닙니다. 매우 짧은 window에서는 refractory dynamics 때문에 underdispersion도 가능합니다. 다만 자연istic event data에서는 unobserved rate variability 때문에 Poisson보다 큰 variance가 흔히 문제가 됩니다.

7. Negative Binomial (NB2): Poisson보다 variance를 더 자유롭게

P001 이후 이 프로젝트에서 사용하는 핵심 count family는 Negative Binomial 2 (NB2)입니다. 평균을 μ, dispersion을 α라고 쓰면:

E[Y] = μ
Var(Y) = μ + α μ2

Poisson과 비교하면 차이가 아주 명확합니다.

MeanVariance추가 parameter
Poissonμμ없음
Negative Binomial (NB2)μμ + αμ²dispersion α ≥ 0

α가 커질수록 같은 mean에서도 distribution이 더 넓어집니다. α→0이면 NB2는 Poisson에 가까워집니다.

NB2 probability mass function

P(Y=y | μ,α) = Γ(y+1/α) / [Γ(1/α)·y!] · [1/(1+αμ)]1/α · [αμ/(1+αμ)]y

이 식 자체를 외울 필요는 없습니다. 프로젝트를 이해하는 데 중요한 것은 μ는 expected count, α는 extra variability를 담당한다는 점입니다.

8. NB가 neural data에 잘 맞는 직관: “firing rate 자체가 매 occurrence마다 흔들린다”

Negative Binomial은 Poisson–Gamma mixture로 이해하면 매우 직관적입니다.

Occurrence마다 latent firing rate λ가 다름→λ ~ Gamma→Y | λ ~ Poisson(λ)→Marginal Y ~ Negative Binomial

즉 “한 neuron의 진짜 firing rate가 모든 transition에서 완전히 동일하다”가 아니라:

Occurrence 1: latent rate λ = 2.1
Occurrence 2: latent rate λ = 6.8
Occurrence 3: latent rate λ = 3.5
Occurrence 4: latent rate λ = 11.2
...

각 occurrence 안에서는 Poisson처럼 spike가 나오더라도,
occurrence 간 λ 자체가 흔들리면 전체 count distribution은 Poisson보다 넓어진다.

자연istic movie experiment에서는 우리가 모델에 넣지 못한 cognitive state와 stimulus factors가 많으므로 이 관점이 특히 설득력이 있습니다.

9. 같은 mean에서 Poisson과 NB를 직접 비교

아래에서 mean μ와 NB dispersion α를 움직여 보세요. 두 분포의 평균은 같지만 NB의 variance와 tail이 얼마나 넓어지는지 볼 수 있습니다.

그래프에서 같은 μ를 유지한 채 α를 키우면 NB의 가운데 peak는 낮아지고, 0 근처와 큰 count 쪽까지 probability가 더 퍼집니다. 이것이 extra-Poisson variability입니다.

10. 왜 neural firing 분석에서 Poisson/NB GLM을 많이 쓰는가?

Data type과 맞는다

Spike count는 continuous Gaussian 값이 아니라 nonnegative integer count입니다. Poisson/NB는 이 support를 직접 모델링합니다.

Mean이 양수로 보장된다

log link를 쓰면 μ=exp(Xβ)이므로 model이 −3 spikes 같은 불가능한 expected count를 예측하지 않습니다.

Stimulus covariates와 연결하기 쉽다

sensory, event type, context, baseline state 같은 predictors가 expected firing을 어떻게 바꾸는지 GLM coefficient로 표현할 수 있습니다.

NB는 trial/event variability를 허용한다

Poisson의 mean=variance 제약보다 실제 반복 event의 heterogeneity를 더 유연하게 표현합니다.

다만 “neural firing이면 무조건 NB”라는 뜻은 아닙니다. 연구 질문과 timescale에 따라 Poisson, quasi-Poisson, NB, zero-inflated model, point-process model, renewal model 등이 모두 가능합니다. 이 프로젝트에서는 event-window spike count가 outcome이고 overdispersion을 허용해야 하므로 NB2가 frozen primary choice입니다.

11. P001 → P002/M0로 실제로 어떻게 연결되는가

P001 row
 ├─ post spike count Y       ───────────────┐
 ├─ baseline spike count B   ───────┐       │
 ├─ movie time / nuisance features ─┤       │
 └─ unit / occurrence identity      │       │
                                    ↓       ↓
                              NB2 regression model

Y_i ~ NB2(μ_i, α)
log μ_i = β0 + βB·Baseline_i + f(movie_time_i) + ...

M1: + sensory features
M2: + structural features
M3: + preceding-context features

여기서 모델 비교의 핵심은 같은 post counts를 설명하면서 추가 feature set이 held-out data의 likelihood를 개선하는가입니다. Baseline은 event effect 그 자체라기보다 각 occurrence의 starting neural state를 조절하는 nuisance covariate 역할을 합니다.

가상의 neuron에서 세 occurrences가 있다고 합시다.

B와 C는 baseline이 똑같이 5입니다. 그런데 C에서 post count가 더 큽니다. 따라서 C의 높은 post firing은 단순히 “이미 baseline이 높았기 때문”으로는 설명되지 않습니다. X가 그 차이를 설명할 후보가 됩니다.

log μ = β0 + βBB + βXX

모델은 여러 occurrences를 이용해 βB와 βX를 동시에 추정합니다. 이것이 baseline을 빼버리는 것보다 “baseline state를 control하면서 X의 추가 explanatory value를 본다”는 질문에 더 직접적입니다.

13. 이 장에서 기억할 것

  1. Outcome은 post spike count로 유지한다.
  2. Baseline은 post에서 기계적으로 빼기보다 predictor/covariate로 넣어 baseline→post 관계를 데이터가 추정하게 한다.
  3. 특히 P001은 baseline 0.8 s, post 1.0 s라 raw count subtraction은 window-length 차이도 무시한다.
  4. Poisson은 count model의 자연스러운 출발점이며 mean=variance를 가정한다.
  5. NB2는 Var(Y)=μ+αμ²로 extra variability를 허용한다.
  6. 자연istic neural data에서는 latent firing rate가 occurrence마다 달라질 수 있어 overdispersion이 생기기 쉽다.
  7. 그래서 이 프로젝트의 event-window spike counts에는 NB2 GLM이 primary model family로 사용된다.

14. 이해 점검

Q1. baseline=4, post=4이면 “event response가 0”이라고 바로 결론 내릴 수 있을까?
정답

아닙니다. 두 windows의 길이도 다르고, baseline과 post는 noisy counts입니다. 더 중요한 분석 질문은 baseline state와 nuisance variables를 조건으로 했을 때 post count가 event features에 의해 설명되는가입니다.

Q2. Poisson에서 mean=5이면 variance는?
정답

5입니다. Poisson의 핵심 제약은 Var(Y)=E[Y]=μ입니다.

Q3. NB2에서 μ=5, α=0.4이면 variance는?
정답

5 + 0.4×25 = 15입니다. 같은 mean=5인 Poisson의 variance 5보다 훨씬 넓습니다.

Q4. α→0이면 NB2는 어떤 분포에 가까워지는가?
정답

Poisson에 가까워집니다.
